Course Overview

The Microsoft Azure Administrator Training (AZ-104) is meticulously designed for cloud administrators responsible for managing and monitoring Azure environments. This course provides in-depth knowledge on implementing core Azure services, ensuring you can competently manage Azure infrastructure. As a participant, you'll learn to handle Azure Active Directory, configure role-based access, manage subscriptions, and deploy resources using templates. Additionally, you will gain expertise in managing storage, virtual networks, and implementing backup and recovery solutions.

Hands-On Projects

Our course emphasizes practical skills through a series of hands-on projects, ensuring you can apply your knowledge in real-world scenarios, such as configuring virtual machines and containers, and managing Azure app services.

Certification Focused

This training aligns with the requirements of the AZ-104 certification exam, equipping you with the knowledge needed to excel in your role as an Azure administrator, often collaborating with various IT teams to deliver comprehensive cloud-based solutions.

What You'll Learn

Implement and manage Azure Active Directory objects.
Configure and manage virtual networks and secure access.
Deploy and manage Azure storage solutions.
Automate resource deployment with ARM templates.
Monitor Azure resources using Azure Monitor.
