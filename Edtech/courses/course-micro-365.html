Course Overview

This hands-on course is tailored for IT professionals eager to master Microsoft 365 administration. You'll delve into essential skills such as managing Exchange Online, leveraging Microsoft Entra ID (formerly Azure AD), and employing PowerShell for automation. Begin with foundational lessons and quickly progress to more advanced topics. At the core, you'll focus on user and license management, complex mail flow scenarios, and implementing robust security practices. Real-world tasks and admin center walkthroughs ensure you gain practical experience, enabling you to apply these skills immediately in your professional environment.

Modules Included

From understanding M365 architecture to setting up retention policies and email flow rules, this course offers a comprehensive curriculum to equip you in your IT role. You'll explore security measures, mobile device management, and learn how to automate admin tasks using PowerShell to enhance efficiency.

What You'll Learn

Understand M365 architecture, roles, and responsibilities
Navigate and customize the Microsoft 365 Admin Center
Manage users, security groups, and roles in Microsoft Entra ID
Assign and manage Microsoft 365 licenses and subscriptions
Configure Exchange Online mailboxes and distribution groups
Implement anti-spam and compliance policies
Automate management tasks with PowerShell
